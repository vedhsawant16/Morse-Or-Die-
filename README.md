# Morse or Die

Decode Morse code before time runs out!

## Play Now
https://yourusername.github.io/morse-or-die/

## Features
- 3 difficulty levels
- Audio-based Morse code decoding
- Score and streak system
- Timer-based challenges

## How to Play
1. Listen to the Morse code.
2. Decode the transmission.
3. Enter your answer.
4. Survive as long as possible!
